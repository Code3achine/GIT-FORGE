# Frontend Specifications

Next.js 14+ App Router, TypeScript, single-page architecture.

Styling: Tailwind CSS + Lucide React icons, dark/light UI.

Markdown preview: `react-markdown` + `react-syntax-highlighter` for live rendering.

Calls backend via `fetch('/api/generate-readme')`, routed through rewrites — see [[06-Deployment-and-Configuration]].
